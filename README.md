# Recipe Library

A mobile-friendly, searchable index of 60 recipes.

## Files
- `index.html` — searchable A–Z recipe dashboard
- `Recipes_with_bookmarks.pdf` — full recipe collection with bookmarks

## Publish with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait a few minutes for the site to publish.

The dashboard and PDF must stay together in the repository root because the index links to `Recipes_with_bookmarks.pdf`.
